*Alphabetical index of all properties in the AlibreScript API*

## Property Categories

### Common Properties
- **Metadata**: Comment, Description, Name, DocumentNumber
- **Geometry**: Center, Radius, Angle, Length, Width, Height
- **Configuration**: Configurations, Parameters, Settings
- **File Info**: FileName, CreatedBy, CreatedDate, LastUpdateDate

### Geometry Properties
- **Points & Centers**: [Center](Circle.md#center), [CenterPoint](Circle.md#centerpoint), [Origin](Sketch.md#origin)
- **Dimensions**: [Radius](Circle.md#radius), [Angle](CircularArc.md#angle), [Length](Line.md#length)
- **Complex Geometry**: [ControlPoints](Bspline.md#controlpoints), [Figures](Sketch.md#figures)

### Part & Assembly Properties
- **Identity**: [Name](Part.md#name), [Description](Part.md#description), [Comment](Part.md#comment)
- **Material**: [Material](Part.md#material), [Density](Part.md#density), [Mass](Part.md#mass)
- **Management**: [Configurations](Part.md#configurations)
